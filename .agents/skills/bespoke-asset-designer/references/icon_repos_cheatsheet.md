# GitHub Asset Repositories Directory (Logo, Banner & Icon Repos)

| Ten Repository | Duong Dan GitHub | Mo Ta & So Luong Asset | Cach Tich Hop |
| :--- | :--- | :--- | :--- |
| **SVGL** | `pheralb/svgl` | Thu vien logo SVG dep nhat hien nay cho web, API va thuong hieu | Shallow clone hoac lay truc tiep file SVG |
| **Simple Icons** | `simple-icons/simple-icons` | 3100+ logo SVG vector chinh thuc cua cac hang va cong nghe | `npm i simple-icons` hoac clone repo |

| **VectorLogoZone** | `vectorlogozone/vectorlogozone` | Kho logo vector cho landing page va dashboard | Tich hop file SVG truc tiep |
