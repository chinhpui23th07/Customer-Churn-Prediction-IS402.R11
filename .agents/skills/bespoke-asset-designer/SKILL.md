# Bespoke Asset Designer Skill

## Mission
Produces distinctive, high-resolution vector SVG assets for projects, establishing an authentic brand identity aligned with domain color palettes.

---

## 1. Design Guidelines
- **No Generic AI Purple Gradients:** Use tailored domain palettes (Oceanic Navy `#0A192F`, Amber `#F59E0B`, Forest Emerald `#10B981`).
- **Scalable Vector Graphics:** Create self-contained SVGs that scale crisply across all display resolutions.
- **Assets Directory:** Persist all brand assets in `assets/logo.svg` and `assets/banner.svg`.
