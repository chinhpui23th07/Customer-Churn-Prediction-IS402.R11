# Stitch UI Architect Skill

## Mission
Designs modern, responsive, and aesthetically pleasing web interfaces governed by `DESIGN.md` and Bento Grid layouts.

---

## 1. Architectural Guidelines
- **Color Discipline:** Natural enterprise palettes (Oceanic Navy `#0A192F`, Amber `#F59E0B`, Forest Emerald `#10B981`).
- **Bento Grid Hierarchy:** Modular card containers for dashboard KPIs, interactive forms, real-time charts, and telemetry.
- **Component Granularity:** Presentation components under 200 lines; dedicated API integration hooks under 150 lines.
- **Loading & Error UX:** Skeletons for pending API responses, distinct badges for health and drift metrics.
