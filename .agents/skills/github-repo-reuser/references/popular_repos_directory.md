# Popular Open-Source Repositories Directory (Danh Mục Repo Chuẩn Theo Tác Vụ)

Bảng tra cứu nhanh các repository GitHub mã nguồn mở chất lượng cao nhất cho các nhu cầu thường gặp:

## 1. Trình Chiếu & Thuyết Trình (Slides & Presentations)
- **Marp CLI (`marp-team/marp-cli`):** Chuyển đổi Markdown thành Slide HTML/PDF cực kỳ nhanh chóng và chuyên nghiệp.
- **Slidev (`slidevjs/slidev`):** Tạo slide cho developer bằng Vue/Vite, hỗ trợ animation, code highlight và interactive components.
- **Reveal.js (`hakimel/reveal.js`):** Khung tạo slide HTML5 kinh điển, hiệu ứng chuyển trang 3D mượt mà.
- **PptxGenJS (`gitbrent/PptxGenJS`):** Thư viện JavaScript tạo file PowerPoint (.pptx) trực tiếp bằng code.

## 2. Giao Diện Người Dùng Đỉnh Cao (UI/UX Libraries)
- **Shadcn UI (`shadcn-ui/ui`):** Bộ component Tailwind CSS có thể copy trực tiếp vào source code, dễ tùy biến nhất hiện nay.
- **Magic UI (`magicuidesign/magicui`):** Hơn 50+ hiệu ứng animation cao cấp (Bento grids, Animated beam, Meteors, Blur fade).
- **Aceternity UI (`aceternity/ui`):** Component animation cực đẹp cho Next.js / Tailwind (Sparkles, Background beams, Card hover).
- **Lucide Icons (`lucide-icons/lucide`):** Bộ icon vector chuẩn mực, đồng nhất và nhẹ nhất cho mọi nền tảng.

## 3. Xử Lý Văn Bản & Chuyển Đổi Dữ Liệu
- **Pandoc (`jgm/pandoc`):** "Con dao pha" chuyển đổi giữa Markdown, LaTeX, Word (.docx), PDF, HTML.
- **Pdfplumber (`jsvine/pdfplumber`):** Bóc tách văn bản, bảng biểu và metadata từ file PDF với độ chính xác cao.
- **Python-docx (`python-openxml/python-docx`):** Thư viện đọc và tạo tệp Word (.docx) chuẩn của Python.

## 4. Tự Động Hóa Trình Duyệt & Web Scraping
- **Playwright (`microsoft/playwright`):** Công cụ tự động hóa trình duyệt nhanh, ổn định và hỗ trợ đa ngôn ngữ.
- **Crawlee (`apify/crawlee`):** Thư viện cào dữ liệu web thông minh, tự động xử lý proxy và tránh bị chặn.
