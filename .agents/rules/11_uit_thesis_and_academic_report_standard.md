# Rule 11: UIT Academic Thesis & Capstone Report Governance Standard

## 1. Scope & Authority
All academic reports, graduation theses, and capstone projects within the University of Information Technology (UIT - VNU-HCM) curriculum must adhere strictly to the university's academic document formatting guidelines.

---

## 2. Formatting Specifications

| Parameter | UIT Official Standard | Implementation Details |
| :--- | :--- | :--- |
| **Typography** | Times New Roman | Body text: **13pt**. Justified alignment. No sans-serif body fonts. |
| **Line Spacing** | 1.5 lines | Consistent throughout all body paragraphs. |
| **Paragraph Spacing** | Before: 0pt, After: 6pt | Prevents unintended blank spaces or text collisions. |
| **Page Margins** | Binding-ready margins | - Left: **3.0 cm** (for thesis spine binding).<br>- Right: **2.0 cm**.<br>- Top: **2.5 cm**.<br>- Bottom: **2.5 cm**. |
| **Page Numbering** | Bottom right or center | - Front matter (Pledge, TOC, Lists): Lowercase Roman numerals (i, ii, iii...).<br>- Core body (Chapter 1 onwards): Arabic numerals (1, 2, 3...). |

---

## 3. Structural Model (6 Standard UIT Chapters)
1. **Official Outer Cover:** Standard border, VNU-HCM and UIT titles, official emblem, faculty name, thesis title, supervisor, student name, student ID, submission year.
2. **Inner Sub-Cover:** Mirrors the outer cover on standard A4 paper.
3. **Pledge of Authorship (Lời Cam Đoan):** Formal affirmation of originality.
4. **Acknowledgments (Lời Cảm Ơn):** Academic and institutional gratitude.
5. **Abstract:** Bilingual executive summary (Vietnamese and English).
6. **Table of Contents, List of Tables, List of Figures, List of Abbreviations.**
7. **Core Content (6 Chapters):**
   - **Chapter 1: OVERVIEW:** Problem statement, research objectives, scope, methodology, literature review & GitHub benchmarking.
   - **Chapter 2: THEORETICAL BACKGROUND & RELATED TECHNOLOGIES:** Problem foundations, ML algorithms, Feature Store architecture, data drift theory.
   - **Chapter 3: SYSTEM ANALYSIS & ARCHITECTURAL DESIGN:** MLOps Level 2 pipeline, data flows, feature store schema, REST API and UI architecture.
   - **Chapter 4: IMPLEMENTATION & EXPERIMENTAL RESULTS:** Real dataset preprocessing (440k records), multi-model training in MLflow, Feast dual-store materialization, drift detection, Bento Grid web dashboard.
   - **Chapter 5: CLOUD BENCHMARKING & PERFORMANCE OPTIMIZATION:** I/O benchmark (Parquet Snappy vs CSV), multi-region network latency measurements, AWS/GCP TCO analysis.
   - **Chapter 6: CONCLUSION & FUTURE WORK:** Key outcomes, limitations, future roadmap.
8. **References:** Strict **IEEE citation standard** ([1], [2], numbered in order of appearance).
9. **Appendices:** Deployment guides, environment configuration, code structure.
